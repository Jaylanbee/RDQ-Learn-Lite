# 學習覆盤卡模板（輕量選項版）

Phase 5 依此模板生成。**硬限制：一個螢幕讀完**（約 40 行內）。

存檔位置：`<筆記庫>/rdq-learn/RDQ-learn-<主題slug>-<YYYYMMDD>.md`

---

## 逐字模板

```markdown
---
rdq_learn_version: 2
topic: <一句話主題，≤30 字>
type: <concept|procedure|transfer|general>
date: <YYYY-MM-DD>
status: draft          # draft → confirmed
telemetry:
  mode: <lite|full>
  rounds: <覆盤輪數>
  questions: <起始問句數>
  q4_prompts: <Ⅳ 菜單條數>
  revisions: 0
---

# RDQ 學習覆盤：<主題名>

## 一句話總結
<由 AI 總結的一句話，點出使用者當前的學習狀態與主要收穫>

## ✅ 已掌握
- <知識點> — 來自信箱：<他主動說出／他選題後浮現>
  <每一條都要記錄它是怎麼被發現的>

## ❓ 待確認
- <疑問或薄弱點> — 當時他 <怎麼回答的>，推測可能 <你的判斷>
  <所有他回答「不確定」、或選題時選到低自信選項的項目>

## 🔍 未探索
- <他選擇現在不碰的項目>
  <Ⅳ 盲點菜單中他沒勾的方向>

## 📋 覆盤摘要
<一段話，包含：
  - 學習者用什麼主題學了什麼
  - 他在哪個方向上最穩固
  - 待確認的薄弱點有哪些
  - 盲點菜單中他選擇了哪些方向探索>

## 📝 下一步行動
- [ ] <1–3 條，從對話中自然長出，不是硬塞的建議>
```

---

## 各段落的功能

| 段落 | 它在解決什麼 |
|---|---|
| ✅ 已掌握 | 讓學習者看見「我到底會了什麼」——尤其選題過程中他自己確認的內容 |
| ❓ 待確認 | 把選題中測出的不確定點顯性化。選到低自信選項的全部列在這裡 |
| 🔍 未探索 | 防止範圍擴張，明確現在不碰什麼 |
| 📋 覆盤摘要 | 讓使用者一眼看完整體狀況 |
| 📝 下一步行動 | 從對話中自然長出，不是硬塞 |

---

## 寫作要求

- 繁體中文
- 關鍵詞（主題名、人名、專有名詞）一律**粗體**
- **一句話總結是由 AI 總結**，不是學習者原句
- ✅ 段落保留來源備註（來自信箱：…）
- 📝 下一步行動不超過 3 條
- 空段落直接省略；示範模式才保留佔位行
